Testing Staging Environment Detection

Test URLs:

  • Local Development
  • Local with Staging Flag

Expected Behavior:

  • Local Development: No staging indicator, console shows "💻 Running in LOCAL/DEVELOPMENT environment"
  • Local with Staging Flag: Shows orange "[STAGING]" badge, console shows "🔧 Running in STAGING environment"

Console Commands to Test:

// Check environment detection
console.log('Is Staging:', window.location.hostname.includes('staging') || 
                        window.location.hostname.includes('preview') ||
                        window.location.search.includes('staging=true'));

// Check if indicator is visible
console.log('Staging Indicator Visible:', 
    document.getElementById('environmentIndicator')?.style.display !== 'none');
